# Essential Vocab 5 — IELTS Vocabulary Learning Platform

Interactive, premium vocabulary platform for Pre-IELTS / IELTS students based on **"4000 Essential English Words Book 5"**.

## 🎨 Design System & Colors
- **Primary:** Soft Blue (`#4A90E2`) & Pastel Teal (`#50E3C2`)
- **Secondary (Gamification):** Muted Coral (`#F5A623`)
- **Background:** Eye-strain reducing Off-White (`#F9FAFB`)
- **Cards/Surfaces:** Pure White (`#FFFFFF`) with soft diffused shadows
- **Text:** Dark Slate (`#1F2937`) headings & Muted Gray (`#4B5563`) body
- **Typography:** Plus Jakarta Sans / Inter

## 🚀 Key Features
1. **Landing Page:**
   - Headline: *"Master IELTS Vocabulary, Effortlessly."*
   - Contextual learning, interactive tasks, and Gift shop rewards preview.
2. **User Dashboard:**
   - Personalized welcome banner with daily goal progress tracker.
   - 3 Gamified Stats Cards: `🔥 Day Streak`, `🪙 Total Coins`, `📚 Words Mastered`.
   - Units grid for Book 5 with *"Unit 1: The Foundations"* and *"Continue Learning"*.
3. **Word Card Interface (Learning Phase):**
   - Word: **Allot** with phonetic `/əˈlɒt/` and verb tag.
   - **[🔊 Listen]** native audio pronunciation via browser Web Speech API.
   - Definition & contextual example.
   - Dual translations: **Uzbek** (`Ajratmoq, bermoq`) & **Russian** (`Выделять, предоставлять`).
   - Clean navigation controls: `[<- Previous Word]` | `[Next Word ->]`.
4. **Interactive Practice Tasks (Earn +10 Coins each):**
   - **Task 1 (Memory):** *"Type the word you just learned."*
   - **Task 2 (Match):** *"Drag the word to its correct definition."*
   - **Task 3 (Listen & Fill):** Audio sentence player & cloze test.
   - Live celebratory confetti and audio pulses upon completion.
5. **Gift Shop (Rewards):**
   - Freeze Streak (Cost: 50 Coins)
   - Dark Mode Theme (Cost: 100 Coins)
   - Golden Crown Avatar (Cost: 500 Coins)

## 💻 How to Run Locally

Open PowerShell or Terminal inside this folder:

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
